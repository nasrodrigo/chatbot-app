# multimodal-chatbot-ui skill

A reusable agent skill for implementing a React Native / Expo multimodal chat UI and device-side input acquisition without implementing chatbot intelligence or backend integration.

## Contents

- `SKILL.md` — workflow, scope boundaries, typed attachment contract, UI requirements, permissions, verification, and handoff.
- `references/expo-media-modules.md` — Expo media module selection and version-aware implementation notes.

This skill is designed to be used alongside the supplied `react-native-project-setup` skill.
